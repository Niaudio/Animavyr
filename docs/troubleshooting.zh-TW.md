# 疑難排解

## 安裝檔 checksum 不符

請勿執行安裝檔。刪除該檔案，再從官方 GitHub Release 頁面重新下載。若仍不符，請建立 Bug Report，且不要附上安裝檔本身。

## Windows 顯示未知發行者警告

目前預設安裝檔未簽章。請先核對下載來源與 SHA-256，再決定是否繼續。詳見[安裝說明](installation.zh-TW.md)。

## LM Studio 或 ComfyUI 無法連線

- 確認服務正在執行。
- 確認 Animavyr 設定的服務位址與連接埠相符。
- 檢查服務本身的 logs 與防火牆設定。
- 檢查匯入的工作流或自訂節點是否需要外部服務位址。

## 專案或媒體檔案無法使用

確認選定的 workspace、磁碟、網路共用位置與引用檔案仍可存取。若檔案在 Animavyr 外被移動或刪除，請從備份還原。
