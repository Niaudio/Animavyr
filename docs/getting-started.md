# Getting Started

1. Install and launch Animavyr.
2. Choose a local workspace directory that you can back up regularly.
3. Create or open a project.
4. Add story, character, world, audio, motion, keyframe, or storyboard material as needed.
5. Optionally configure your local LM Studio and ComfyUI endpoints in Settings.

Animavyr keeps project assets in the selected local workspace. Back up that directory before major OS, disk, model, workflow, or application changes.
