# System Requirements

| Item | Minimum | Recommended for local AI |
| --- | --- | --- |
| Operating system | Windows 10/11, 64-bit | Windows 11, 64-bit |
| Storage | Enough space for the App and project files | Additional SSD space for models and generated media |
| GPU | Integrated graphics for non-generation workflows | NVIDIA GPU with VRAM appropriate for selected models |
| Local AI | Not required | Separately installed LM Studio and/or ComfyUI |

Actual CPU, RAM, VRAM, and storage needs depend primarily on the models, custom nodes, and workflows selected by the user.
