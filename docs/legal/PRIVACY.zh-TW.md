# Animavyr 隱私權政策

最後更新：2026-05-30

## 1. 摘要

Animavyr 預設不收集使用者帳號資料、使用統計、崩潰回報、雲端專案內容或遙測資料。本 App 的設計重點是讓故事、角色、場景、圖片、影片、音訊、工作流與輸出檔案保留在使用者本機 workspace 或瀏覽器儲存空間中。

## 2. 本機保存的資料

本 App 可能在使用者裝置上保存下列資料：

- 使用者選擇的 workspace handle 與專案資料夾內容。
- 專案設定、工作流設定、提示詞範本、AI Copilot 範本與介面偏好。
- IndexedDB 中的本機設定、最近使用專案、UI 狀態與瀏覽器授權資訊。
- 使用者建立或匯入的文字、圖片、影片、音訊、workflow JSON、metadata 與輸出檔案。
- Tauri 桌面版使用的本機授權檔、授權狀態、版本資訊與到期日。

這些資料主要保留在使用者本機磁碟或瀏覽器儲存空間。Animavyr 預設不會將上述資料傳送到 Animavyr 控制的伺服器。

授權檔驗證目前以本機離線驗證為主。授權檔可放在 App 設定目錄中的 `license.animavyr.json`，或由 `ANIMAVYR_LICENSE_FILE` 指向指定路徑。若未來加入伺服器啟用、帳號登入或線上授權同步，Animavyr 會在啟用前更新本政策並說明會傳送的資料項目。

## 3. 本地 AI / 生成服務與自訂工作流端點

本 App 目前僅直接支援使用者本機執行或自行連線的 LM Studio 與 ComfyUI。當使用者執行 AI 分析、提示詞協作、圖片 / 影片 / 音訊生成、workflow 任務或資源協調時，本 App 可能會依使用者操作，將下列資料送往使用者設定的本地 LM Studio 或 ComfyUI 端點：

- 提示詞、故事片段、角色設定、場景描述、鏡頭資訊與使用者指示。
- 參考圖片、影片、音訊或其壓縮 / 轉換版本。
- ComfyUI workflow JSON、節點參數、生成設定、任務 ID 與狀態查詢。
- 為取得生成結果而需要的輸出檔案 URL 或檔案請求。

使用者匯入或自訂的 ComfyUI workflows、custom nodes 或模型節點可能包含外部 API 呼叫。執行這類工作流時，上述資料可能會送往使用者設定或該工作流指定的服務端點。Animavyr 不控制這些端點的資料保存、日誌、模型、網路安全、授權條款或隱私政策。使用者應自行確認端點是否可信、是否位於本機、是否連向雲端，以及是否符合專案素材與客戶資料的保密要求。

## 4. 預設不使用遙測

目前版本預設不收集：

- App 使用統計。
- 自動崩潰回報。
- 裝置識別碼或廣告識別碼。
- 雲端專案內容。
- 使用者行為分析事件。

若未來提供遙測、錯誤回報、雲端備份、帳號登入或同步服務，Animavyr 會在收集前更新本政策，說明資料項目、用途、保存期限、第三方處理者與退出方式，並提供必要的同意或退出選項。

## 5. File System Access API 與瀏覽器權限

本 App 使用瀏覽器 File System Access API 讀寫使用者選擇的 workspace。使用者可透過瀏覽器權限設定撤回資料夾存取權。

若權限失效，本 App 可能要求使用者重新授權 workspace，以便繼續讀寫專案資料。撤回權限不會自動刪除本機磁碟上的專案檔案。

## 6. 資料保留與刪除

使用者可透過檔案系統刪除 workspace、專案資料夾、輸出檔案、工作流與素材。瀏覽器 IndexedDB 中的本機設定可透過瀏覽器清除網站資料、App 的重設設定功能或未來提供的清除工具移除。

刪除本機資料不一定會刪除已傳送到使用者設定的 LM Studio / ComfyUI 端點，或由自訂工作流觸發之外部 API 的資料。請依相關服務的政策、日誌與資料刪除機制處理。

## 7. 兒童與敏感資料

本 App 並非特別設計給兒童使用。使用者不應在未取得合法授權或同意的情況下，輸入高度敏感個人資料、未成年人資料、醫療資料、財務資料、身份證件、機密商業資料或他人受保護內容。

## 8. 安全

Animavyr 採 local-first 設計，但本機安全仍取決於使用者裝置、瀏覽器、workspace 存放位置、本地 LM Studio / ComfyUI 端點、自訂工作流可能連接的外部 API 與網路環境。使用者應自行採取備份、磁碟加密、權限控管、防毒與可信端點設定。

## 9. 政策更新

本政策可能隨產品功能、發行方式、平台要求或法律要求更新。重大變更將以 App、網站、發行頁或其他合理方式通知。
