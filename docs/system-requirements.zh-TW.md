# 系統需求

| 項目 | 最低需求 | 本機 AI 建議配置 |
| --- | --- | --- |
| 作業系統 | Windows 10／11，64 位元 | Windows 11，64 位元 |
| 儲存空間 | 足以容納 App 與專案檔案 | 額外 SSD 空間供模型與生成媒體使用 |
| GPU | 非生成工作流程可使用內建顯示晶片 | 依所選模型配置適當 VRAM 的 NVIDIA GPU |
| 本機 AI | 非必要 | 另外安裝 LM Studio 與／或 ComfyUI |

實際 CPU、RAM、VRAM 與儲存空間需求，主要取決於使用者選擇的模型、自訂節點與工作流。
