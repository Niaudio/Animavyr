# Privacy and Local AI

Animavyr is designed around a local-first workspace. Project files are primarily stored in the workspace selected by the user.

When LM Studio or ComfyUI features are used, Animavyr sends task data to the endpoint configured by the user. A custom workflow or custom node may call an external service even when the configured ComfyUI server is local. Review imported workflows, nodes, models, and endpoint settings before using confidential material.

See the full [Privacy Policy](../PRIVACY.md) for the governing details.
