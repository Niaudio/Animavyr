# Animavyr

Animavyr is a local-first creative production workspace for animation creators, storytellers, and AI-assisted visual pipelines.

[Download the latest Windows release](https://github.com/Niaudio/Animavyr/releases/latest) · [繁體中文](README.zh-TW.md)

> This public repository contains product information, documentation, issue tracking, and official release downloads. The Animavyr application source code is not published here and remains proprietary.

## Highlights

- Organize stories, characters, worlds, audio, motion, keyframes, storyboards, and exports in one workspace.
- Keep project files in a user-selected local workspace.
- Connect to user-managed LM Studio and ComfyUI services when local AI features are needed.
- Reuse ComfyUI workflows, prompts, and production assets across projects.

## Download

- [Latest release page](https://github.com/Niaudio/Animavyr/releases/latest)
- [Direct Windows x64 installer](https://github.com/Niaudio/Animavyr/releases/latest/download/Animavyr-Setup-x64.exe)

Animavyr currently distributes an unsigned NSIS installer. Windows may display an unknown-publisher or SmartScreen warning. Verify the attached SHA-256 checksum before installation.

## System Requirements

- Windows 10 or Windows 11, 64-bit.
- LM Studio and ComfyUI are optional, separately installed services for local AI workflows.
- GPU and VRAM requirements depend on the models and workflows selected by the user.

See [System Requirements](docs/system-requirements.md) and [Installation](docs/installation.md).
