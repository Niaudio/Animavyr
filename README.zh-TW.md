# Animavyr

Animavyr 是為動畫創作者、故事工作者與 AI 視覺工作流打造的 local-first 創作製作空間。

[下載最新版 Windows App](https://github.com/Niaudio/Animavyr/releases/latest) · [English](README.md)

> 這個公開 repository 只提供產品資訊、文件、問題回報與官方下載。Animavyr App 原始碼不在此公開，並維持 proprietary software。

## 核心特色

- 在同一個 workspace 管理故事、角色、世界觀、音訊、動作、關鍵影格、分鏡與輸出。
- 專案檔案保留在使用者選擇的本機 workspace。
- 需要本機 AI 功能時，可連接由使用者自行管理的 LM Studio 與 ComfyUI。
- 跨專案重用 ComfyUI workflows、提示詞與製作素材。

## 下載

- [最新版本頁面](https://github.com/Niaudio/Animavyr/releases/latest)
- [直接下載 Windows x64 安裝檔](https://github.com/Niaudio/Animavyr/releases/latest/download/Animavyr-Setup-x64.exe)

Animavyr 目前提供未簽署的 NSIS 安裝程式，因此 Windows 可能顯示未知發行者或 SmartScreen 警告。安裝前請核對 Release 附帶的 SHA-256。

## 系統需求

- Windows 10 或 Windows 11，64 位元。
- LM Studio 與 ComfyUI 為選用且需另外安裝的本機 AI 服務。
- GPU 與 VRAM 需求取決於使用者選擇的模型與工作流。

請參閱[系統需求](docs/system-requirements.zh-TW.md)與[安裝說明](docs/installation.zh-TW.md)。
